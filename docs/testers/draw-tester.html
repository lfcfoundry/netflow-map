What is measured

For each size, a fresh copy of the app is opened in a hidden frame with the drawing choice set (plain canvas, or automatic), a made-up network of that many items with six communities is brought in, and the clock runs from that moment until the Map has laid out the picture, made the scene and drawn two frames. Each pair takes turns with the order swapped every round, and every run uses a different made-up network so a saved layout is never reused. The "drawing step" is the picture handed to the drawing code again and drawn, three times (middle one), each until two frames have passed. The app version, cores, memory and graphics card are in the results.
