# First release code, kept for the comparison page

`engine.js`, `scene.js`, `render.js` and `probe.js` here are copies of `src/engine.js`, `src/scene.js`, `src/render.js` and `src/probe.js` from commit 48df84a (only the retired app name in their top comments is changed) (2026-10-14 21:38 US Eastern, "Net Flow Map v0"), the first stamped build 2026.10.14.2136 (the app was named "Net Flow Map" then; the name is "Netflow Map" now). They are only read by `tools/build-then-and-now.mjs`, which puts them next to the current engine and scene inside `bench/netflow-map-then-and-now.html` so the two can be timed one after the other in the same browser.
