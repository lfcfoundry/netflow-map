Netflow Map: first version vs now

Lays out the same maps with the very first Netflow Map (2026.10.14.2136, then called Net Flow Map) and with the version in this page (2026.10.17.2329, with every update since), taking turns, and tells you in plain words what changed. Nothing leaves this page.

    Plain takeaway: at these sizes the page uses about the same memory as the first version, a little more right after building because the app now keeps more (chapters, mini-map, link look-up). The memory savings come on very big maps: at 100,000 items, packing idle links saves 67 MB (402 → 335 MB) against the build just before that step. I did not run the first version at 100,000 items (it needs minutes), so there is no first-release figure there.

    New since the first version (not in the first version at all)

    Hovering a link shows it, and the first hover on a 30,000-item map takes 316 ms in Chromium 155, 279 ms in Firefox 158, 77 ms in WebKitGTK 2.52.6 and 134 ms in GNOME Web 46.5 (lower is better). Also new: a rough early picture while big maps finish, the multilevel layout for huge networks, reuse of the last layout when you only change the look, Top-down options (story order, chapters, mini-map, bundled and tapered links), and a leaner idle state (the layout worker rests after 4 seconds).
